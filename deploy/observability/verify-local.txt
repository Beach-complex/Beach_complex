로그 파이프라인 로컬 검증

준비
- 저장소 루트에서 실행한다.
- Docker Engine + Compose v2 이상, Python 3, Terraform 1.15.8, cloud-init이 필요하다.
- AWS 자격증명이나 실제 AWS 리소스는 필요하지 않다.
- 기존 beach.logs=backend 컨테이너가 있으면 중지 상태여도 통합 테스트가 중단된다.
  이 경우 별도의 테스트용 Docker 데몬에서 실행한다.

1. 설정 검사: Terraform mock plan 3건, cloud-init, Compose, Loki/Alloy
bash deploy/observability/scripts/validate-iac.sh

2. 통합 테스트: Docker 로그 수집, 회전 복구, 긴 JSON 재조립, Grafana/Tempo 연결
python3 deploy/observability/scripts/verify-log-pipeline.py

3. 결과 확인
cat build/reports/observability/log-pipeline.json

통합 테스트가 만든 컨테이너와 볼륨은 종료 시 자동으로 정리한다.
서버 적용과 실제 앱 검증은 별도로 수행한다.
자세한 검증 범위와 적용 절차: deploy/observability/README.md
